# 🌱 AI-Powered NDVI Crop Monitoring & Forecasting

An AI-powered web application that monitors crop health using Sentinel-2 satellite imagery and forecasts future NDVI values with Deep Learning. The project combines Google Earth Engine, Streamlit, and LSTM models to help monitor vegetation health and identify potential crop stress.

## 🚀 Features

- 🛰️ Fetch Sentinel-2 satellite imagery using Google Earth Engine
- 🌿 Calculate and visualize NDVI (Normalized Difference Vegetation Index)
- 📍 Interactive map for region-based analysis
- 📈 NDVI time-series visualization
- 🤖 LSTM-based NDVI forecasting
- ⚠️ Crop stress prediction
- 📊 Weekly NDVI analysis
- 📁 Export NDVI data as CSV
- 💻 Interactive Streamlit dashboard
